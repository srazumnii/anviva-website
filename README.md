# Anviva website

Static marketing / support / privacy pages for Anviva.

## Hosting

Connect this repository to **Netlify**, **Vercel**, or **GitHub Pages**.

- **Publish directory:** / (site root — index.html is at the repository root)
- No build step required

### GitHub Pages

Settings > Pages > Source: Deploy from a branch > main / / (root).

### Netlify / Vercel

Import this repo; leave build command empty and set the publish/output directory to / or ..
